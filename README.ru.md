# Paragraph Swipe (русский)

[English](README.md)
WARNING: плагин в активной фазе разработки и тестирования, может произойти что угодно.

Свайпни вправо по абзацу → выбери куда отправить текст
Сделан под **Android** (сенсорный экран, без клавиатуры). 

## Настройки

| Параметр | Смысл |
|---|---|
| debug | вкл/выкл дебаг |
| swipe trashhold | трешхолд срабатывания свайпа |

## Что именно считается абзацем

Абзац = подряд идущие непустые строки, отделённые пустой строкой. Соседние пустые строки
схлопываются в одну. Если свайп пришёлся на пустую строку,
берётся ближайший непустой абзац (сначала снизу).
